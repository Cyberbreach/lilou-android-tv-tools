# Lilou — Android TV Tools

Strumento per lavorare su Android TV e TV box: collega, pulisci (Turbo), installa, personalizza (temi e sfondi), privacy & rete, recupero/firmware.

## Download / Aggiornamenti
Scarica dalla pagina **Releases**:
- Windows: `Lilou-Setup.exe`
- macOS (Intel): `Lilou.dmg`

adb, fastboot e .NET sono già inclusi — nessuna installazione manuale. Gli aggiornamenti successivi arrivano da soli dal software (Info su Lilou → Controlla aggiornamenti).
